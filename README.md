# 🛒 Carrito de Compras - React & Bootstrap

## 📝 Descripción

Este proyecto consiste en la maquetación profesional de una aplicación de **Carrito de Compras** desarrollada con **React**. La aplicación permite la navegación entre diferentes secciones (Inicio, Artículos y Props) mediante una interfaz dinámica y moderna, simulando un entorno real de comercio electrónico con visualización de productos y navegación interactiva.

El objetivo principal es aplicar buenas prácticas de desarrollo frontend, organización modular de componentes y diseño responsivo utilizando herramientas modernas.

---

## ✨ Características Principales

* **Navegación SPA:** Implementación de rutas dinámicas con `react-router-dom`, permitiendo una navegación fluida sin recargar la página.
* **Diseño Responsivo:** Interfaz desarrollada con **Bootstrap 5**, adaptable a computadoras, tablets y dispositivos móviles.
* **Arquitectura Modular:** Código organizado en componentes reutilizables, facilitando el mantenimiento y la escalabilidad.
* **Estructura de Layout Global:** Implementación de Header, Content y Footer para mantener consistencia visual en toda la aplicación.
* **Uso de Vite:** Entorno de desarrollo rápido y optimizado para proyectos modernos con React.

## 🏗️ Arquitectura del Proyecto

El proyecto sigue una estructura organizada por funcionalidades dentro de la carpeta `src`:

**public/img/**
Contiene las imágenes y recursos visuales utilizados en la aplicación.

**src/features/layout/components/**
Componentes principales del layout:

* `Header.jsx` → Barra de navegación principal
* `Content.jsx` → Vista principal con los productos
* `Footer.jsx` → Pie de página
* `Article.jsx` → Vista de artículos
* `Props.jsx` → Ejemplo de uso de props en React

**src/shared/styles/**
Archivos de estilos personalizados:

* `App.css`
* `index.css`

**src/**

* `App.jsx` → Componente principal con configuración de rutas
* `main.jsx` → Punto de entrada de la aplicación
* `Routes.jsx` → Definición de navegación
